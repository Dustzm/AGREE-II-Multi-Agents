# Project Workflow

This document outlines the standard workflow for development tasks within this project.

## Core Principles
1.  **Test-Driven Development (TDD):** Write tests before implementing features whenever possible.
2.  **Code Quality:** Adhere to the defined [Code Style Guides](./code_styleguides/).
3.  **Documentation:** Keep documentation up-to-date with code changes.

## Task Workflow
For each task in your plan:

1.  **Understand:** Read the task description and relevant code.
2.  **Plan:** Briefly outline your approach.
3.  **Test:** Write or update unit tests to define expected behavior.
4.  **Implement:** Write the code to pass the tests.
5.  **Verify:** Run tests and linters to ensure quality.
    -   Required Test Coverage: >80% (Recommended)

## Phase Completion
At the end of each phase:
1.  **Review:** Check all tasks in the phase are marked as complete.
2.  **Verify:** Run the full test suite to ensure no regressions.
3.  **Manual Check:** Perform a manual verification if required by the protocol.
